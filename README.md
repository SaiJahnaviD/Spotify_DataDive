# 🎵 Spotify Tracks Data Analysis
---

## WHAT
- End-to-end data analysis of Spotify tracks using **R_Language**.
- Transforms raw track metadata and audio features into actionable insights.
- Explores patterns in track popularity, artist collaborations, and audio characteristics.
- Project Duration: 14 weeks of hands-on analysis and workflow development.
- Published In: Quarto ([View Online](https://dsj.quarto.pub/r_datadive/))
---

## WHY
- Music industry relies on data-driven insights for playlist optimization and marketing.
- Analysts need reproducible workflows to process large-scale track datasets efficiently.
- Helps understand listener preferences and track performance trends.

---

## TOOLS
- **R** – Data wrangling, analysis, and scripting
- **tidyverse (dplyr, ggplot2, tidyr)** – Data transformation and visualization
- **lubridate** – Handling release dates and timestamps
- **readr / readxl** – Loading CSV/Excel datasets
- **Kaggle Spotify Datasets** – Source for track metadata and audio features
- **R Markdown / Quarto** – Reproducible reporting and dashboards

---

## GOAL
- Analyze Spotify track datasets to identify factors influencing track popularity.
- Understand genre trends and patterns in artist collaborations.
- Provide insights for playlist optimization, music marketing, and content strategy.

**Key Insights Targeted:**
- Popularity trends across **genres, artists, and release years**.
- Correlation between **audio features** (energy, valence, danceability, tempo) and track popularity.
- Collaboration trends between artists.
- Identification of high-performing tracks and genre patterns.

---

## PROCESS OVERVIEW
1. **Extract:** Collected Spotify track datasets with metadata and audio features from Kaggle.
2. **Transform:** Cleaned missing values, normalized numerical audio features, and created categorical features (genre, decade, popularity tiers).
3. **Load:** Prepared R data frames for analysis and visualization.
4. **Analyze:** Performed exploratory data analysis (EDA) to explore correlations and trends.
5. **Visualize:** Created interactive and static visualizations using ggplot2 and R Markdown.
6. **Decide:** Derived actionable insights for music marketing, playlist curation, and content strategy.

---

**Key Data Frames:**
- `tracks` → Track metadata (track_id, artist(s), album, release_year, genre)
- `audio_features` → Acoustic features (danceability, energy, valence, loudness, tempo)
- `popularity` → Popularity scores per track

---

## VISUALIZATION INSIGHTS
- Distribution of **track popularity** across genres and release years.
- **Correlation heatmaps** of audio features vs. popularity.
- Artist collaboration networks and top collaborating artists.
- Trend analysis of track releases over decades.
- Identification of **high-performing tracks** and genre patterns.
